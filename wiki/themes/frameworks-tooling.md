# 🛠️ Frameworks & tooling

_Frameworks and libraries for building agents._

## Concepts (11)

### 🟡 Tradeoff / intermediate
- **[RAISE](../concepts/raise.md)** — a variant of ReAct enriched with a memory component to retain context across steps.
- **[Swarm behaviors (flocking / swarming)](../concepts/flocking-swarming.md)** — coordinate a crowd of agents through a few bio-inspired local rules, with no central controller.

### 🟢 Overview / introductory
- **[AutoGen & AG2](../concepts/autogen-ag2.md)** — Microsoft's multi-agent framework for asynchronous conversations between agents (an AssistantAgent that "thinks," a UserProxyAgent that executes), extended by a community fork, AG2.
- **[BeeAI](../concepts/beeai.md)** — a framework-agnostic orchestration layer from IBM, built on the ACP protocol, that discovers, runs and shares agents regardless of their frameworks, isolating each agent in its own container.
- **[CrewAI](../concepts/crewai.md)** — a multi-agent framework built on LangChain that organises agents into a "crew" via roles, tasks and processes (sequential or hierarchical with an auto-generated manager).
- **[LangChain](../concepts/langchain.md)** — an open-source orchestration framework that provides modular abstractions (chains, indexes, memory, tools, agents) to build LLM-driven applications, pluggable onto almost any model.
- **[LangFlow](../concepts/langflow.md)** — a low/no-code drag-and-drop GUI to assemble agents, LLMs, and RAG systems by connecting modular components, with flows exportable as JSON.
- **[LangGraph](../concepts/langgraph.md)** — LangChain's orchestration framework that models an agent workflow as a state graph (nodes, edges, cycles) with explicit state management and human-in-the-loop.
- **[LlamaIndex](../concepts/llamaindex.md)** — an agent orchestration framework whose basic unit is the event-driven *workflow*: steps triggered by events and connected by a shared context, with no predefined paths between them.
- **[OpenAI Swarm](../concepts/openai-swarm.md)** — an OpenAI framework where each agent is a specialized unit and control is passed from one agent to another (handoff) over the course of the conversation.
- **[Semantic Kernel](../concepts/semantic-kernel.md)** — Microsoft's agent SDK, with two built-in agent types (chat-completion and assistant) and a Process Framework to orchestrate step-based workflows.
