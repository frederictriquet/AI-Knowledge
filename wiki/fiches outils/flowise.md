# Flowise

**En une phrase** — Builder **visuel drag-and-drop** open-source pour construire des apps LLM, des chaînes et des agents sans (ou avec peu de) code ; self-host gratuit ou Flowise Cloud managé.

## Type & intégration
Canvas low-code où l'on assemble nœuds (LLM, retrievers, outils, mémoire, agents) en flux exécutables, exposés ensuite en API/chatbot. Déployable partout (Docker, AWS, Azure, GCP, Railway…). ~54k★ sur GitHub.

## Modèle économique
**Open-source — Apache 2.0**, self-hosting **gratuit**. **Flowise Cloud** : alternative hébergée managée (offres payantes ; prix non détaillés à la source — à vérifier sur la page pricing).

## Coût LLM
**🔑 BYOK** : tu connectes tes propres providers (OpenAI, Anthropic, modèles locaux…) ; Flowise ne facture pas les tokens, tu paies tes fournisseurs en direct.

## À quoi ça sert
Prototyper et déployer vite des apps/agents LLM **visuellement**, sans bâtir tout le code d'orchestration. Brique de construction de produit IA (vs un framework code comme LangGraph/CrewAI). Voisin de Sim, Dify, Langflow.

## Notes / à creuser
- Apache 2.0 « propre » (pas de clause restrictive) → adoption sans friction.
- ⚠️ Low-code = plafond de complexité : au-delà du prototypage, débogage et versionnement des flux visuels deviennent pénibles ; les ~54k★ ne disent rien de la maturité en production. Pour un besoin custom, un framework code reste plus souple.
