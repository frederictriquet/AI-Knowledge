# Continue

**En une phrase** — Assistant de codage IA open-source (extensions VS Code / JetBrains + CLI) entièrement **model-agnostic** : tu branches les modèles de ton choix ; un Hub permet de partager assistants, règles et modèles.

## Type & intégration
Extensions IDE (VS Code, JetBrains) + CLI, avec autocomplétion, chat et mode agent. Continue Hub : catalogue d'« assistants » et de building blocks (modèles, règles, MCP) réutilisables. ⚠️ **Statut** : Continue a été **racheté par Cursor** (annonce 2026-04-27) ; le produit/abonnement standalone est en cours d'arrêt, mais le **codebase open-source reste disponible** comme fondation. (Contexte : Anysphere/Cursor lui-même en cours de rachat par SpaceX, annoncé 2026-06-16.)

## Modèle économique
Cœur **open-source (Apache 2.0)**, historiquement freemium (offres Solo gratuite / Teams / Enterprise autour du Hub). ⚠️ Avec le rachat, l'avenir des offres payantes est incertain — à reconfirmer. Le code OSS, lui, reste exploitable.

## Coût LLM
**🔑 BYOK** : Continue n'embarque pas de modèle — tu connectes tes propres providers (Anthropic, OpenAI, Mistral, modèles locaux via Ollama…) et paies le fournisseur en direct.

## À quoi ça sert
Avoir un assistant de codage **ouvert et configurable** (choix du modèle, règles d'équipe, blocks partagés) plutôt qu'un IDE fermé. Historiquement la principale alternative open-source à Copilot/Cursor.
