# Task Master (Taskmaster)

**In one sentence** — a tool (CLI + MCP server, by eyaltoledano) that turns a PRD into a **list of structured tasks** (dependencies, priorities, acceptance criteria) to move from "vibe coding" to predictable execution by agents.

## Type & integration
Works as a standalone **CLI** **and** as an **MCP server**: native integration with Claude Code, plus support for Cursor, Windsurf, VS Code via MCP — the agent directly calls the commands (generate/break down/order tasks). ~25k★ on GitHub.

## Pricing model
**Open-source MIT core**, free for solo dev. Paid offering: **Hamster Studio** (a team platform: collaborative briefs, real-time editing, team plans, issue-tracker sync).

## LLM cost
- **🔑 BYOK** (local mode): your own keys, 15+ providers (Anthropic, OpenAI, Gemini, Perplexity, Ollama…).
- **🟢 Hosted** ("connected to Hamster" mode): hosted inference without a key.

## What it's for
Giving the agent a **disciplined task plan** derived from a spec/PRD, and keeping it on track on multi-step projects. A complement to spec-driven methodologies (Spec Kit, BMAD).

## Notes
- Distinguish the free CLI/MCP core (MIT) from the Hamster platform (paid, team).
- Very popular in the Cursor/Claude Code ecosystem.
- ⚠️ Heavily overlaps Spec Kit / BMAD (planning from a PRD): an overlap to arbitrate rather than stack; unjustified overhead on short tasks.
