# Pheromind

**In one sentence** — Multi-agent orchestration framework based on **"pheromone-based" swarm intelligence**: specialized agents coordinate indirectly through a shared information medium ("digital scent") to run complex projects (especially software dev cycles).

## Type & integration
Orchestration layer on top of coding agents: a high-level orchestrator produces natural-language summaries translated into "digital pheromones" that guide the swarm's behavior (dynamic task allocation, emergent coordination, no central bottleneck).
