# Crystal

**In one sentence** — Desktop app (Electron, Stravu) to launch and compare **several Claude Code / Codex sessions in parallel** in isolated git worktrees, then merge the best approach.

## Type & integration
Local desktop application: you create several agent sessions on distinct git worktrees, have them work in parallel on variants, inspect/test, and merge. ⚠️ **Deprecated (Feb. 2026)**: replaced by **Nimbalyst** (active successor — adds session kanban, visual markdown/mockup/diagram editors, iOS app). Crystal remains usable but is no longer maintained.

## Pricing model
**Open-source MIT**, free. Crystal adds no cost of its own; you use your existing Claude Code or Codex subscriptions/keys.

## LLM cost
**🟢 BYO agent**: Crystal drives agents you supply (Claude Code, Codex) with their own auth → no LLM key nor billing of its own.

## What it's for
Parallelize the work of a coding agent (testing several approaches at once rather than sequentially) without managing worktrees by hand. Same family as Conductor, Orca, Vibe Kanban.

## Notes
- ⚠️ Prefer **Nimbalyst** for long-term use (Crystal is no longer updated).
- Maintained competitors: Conductor, Orca, Supacode, Vibe Kanban.
