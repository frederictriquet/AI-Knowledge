# dupehound

**In one sentence** — open-source (MIT, Rust) **duplicate-code** detector designed for codebases where AI writes most of the code: spots duplicated functions **even when identifiers and literals are renamed**, by fingerprinting the *structure* (not the text), 100% local and deterministic — **without any LLM or key**.

## Type & integration
**CLI** + **MCP server** mode. Four uses:
- `scan` — reports duplication clusters + a repo-level **"slop score"**.
- `history` — tracks duplication along git history.
- `check` — **CI gate** that fails when a change duplicates existing code.
- `mcp` — runs as an **MCP server**, exposing tools the coding agent calls **during editing** ("does this already exist?" → reuse instead of rewriting).

Under the hood: **tree-sitter** parsing + a **winnowing** algorithm (fingerprinting). Implemented in Rust.

## Pricing model
**Open-source, free**, **MIT** license.

## LLM cost
**🟢 Built-in.** dupehound **uses no LLM**: "no network, API keys, or AI required", deterministic static analysis, local and offline. In MCP mode it runs *in/alongside* the agent (Claude Code…) with no key of its own → no separate LLM cost.

## What it's for
Fighting **duplication / "slop"** generated by coding agents: making them **reuse** existing code rather than rewrite it (via MCP, mid-edit), measuring duplication debt (slop score, historical curve) and **blocking in CI** the PRs that re-duplicate. Neighbour by intent to [Ponytail](ponytail.md) (anti-over-engineering: less code) — but here by **deterministic measurement** of duplication, not prompt steering. To be distinguished from the LLM-based AI reviewers of the [AI code review](../guides/generate-code-with-ai.md#fam-ai-code-review) family.

## Notes
- **Young**: v0.1.2 (June 2026), ~64★. Scope/robustness to be validated on large multi-language repos.
- The "slop score" is an in-house heuristic — useful as a **trend signal**, not to be taken as absolute.
- Structural detection (renaming-tolerant) ≠ semantic detection: two genuinely different implementations of the same intent will not be seen as duplicates.
