# Flowise

**In one sentence** — open-source **visual drag-and-drop** builder for LLM apps, chains and agents with little or no code; free self-host or managed Flowise Cloud.

## Type & integration
Low-code canvas where you assemble nodes (LLM, retrievers, tools, memory, agents) into executable flows, then exposed as an API/chatbot. Deployable anywhere (Docker, AWS, Azure, GCP, Railway…). ~54k★ on GitHub.

## Pricing model
**Open-source — Apache 2.0**, self-hosting **free**. **Flowise Cloud**: managed hosted alternative (paid tiers; prices not detailed at the source — to be checked on the pricing page).

## LLM cost
**🔑 BYOK**: you connect your own providers (OpenAI, Anthropic, local models…); Flowise does not bill tokens, you pay your providers directly.

## What it's for
Quickly prototyping and deploying LLM apps/agents **visually**, without building all the orchestration code. A building block for an AI product (vs a code framework like LangGraph/CrewAI). Neighbour of Sim, Dify, Langflow.

## Notes
- "Clean" Apache 2.0 (no restrictive clause) → frictionless adoption.
- ⚠️ Low-code = complexity ceiling: beyond prototyping, debugging and versioning visual flows becomes painful; the ~54k★ say nothing about production maturity. For a custom need, a code framework remains more flexible.
