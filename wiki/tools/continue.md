# Continue

**In one sentence** — Open-source AI coding assistant (VS Code / JetBrains extensions + CLI) that is fully **model-agnostic**: you plug in the models of your choice; a Hub lets you share assistants, rules and models.

## Type & integration
IDE extensions (VS Code, JetBrains) + CLI, with autocomplete, chat and an agent mode. Continue Hub: a catalogue of reusable "assistants" and building blocks (models, rules, MCP). ⚠️ **Status**: Continue was **acquired by Cursor** (announced 2026-04-27); the standalone product/subscription is being wound down, but the **open-source codebase remains available** as a foundation. (Context: Anysphere/Cursor itself is in the process of being acquired by SpaceX, announced 2026-06-16.)

## Pricing model
**Open-source (Apache 2.0)** core, historically freemium (free Solo / Teams / Enterprise tiers around the Hub). ⚠️ With the acquisition, the future of the paid offerings is uncertain — to be reconfirmed. The OSS code itself remains usable.

## LLM cost
**🔑 BYOK**: Continue embeds no model — you connect your own providers (Anthropic, OpenAI, Mistral, local models via Ollama…) and pay the provider directly.

## What it's for
Having an **open and configurable** coding assistant (model choice, team rules, shared blocks) rather than a closed IDE. Historically the main open-source alternative to Copilot/Cursor.

## Notes
- ⚠️ **Longevity**: project absorbed by Cursor → favour the fork/OSS code if you want to rely on it long-term; watch post-acquisition announcements.
- Open-source lineage close to Cline / Roo Code (other BYOK VS Code extensions).
