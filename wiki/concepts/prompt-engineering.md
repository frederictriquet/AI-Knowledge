# What is prompt engineering

**In one sentence** — the discipline of designing and iteratively refining the text instructions given to an LLM to steer its output.

## In detail
Prompt engineering refers to crafting requests that help generative-AI models understand not only the language but also the nuance and intent behind the request. The basic rule is that "good prompts give good results": a well-designed prompt reduces the need for post-generation revision and editing. The process rests on iterative refinement: the engineer refines prompts based on the model's responses. The expected skills are: knowledge of LLMs, communication, technical popularization, Python proficiency, data structures and algorithms, creativity, and realistic risk assessment. Three advanced techniques are distinguished: zero-shot, few-shot, and chain-of-thought (CoT). Cited use cases: chatbots, healthcare, software development, software engineering, cybersecurity.

## Example
The source illustrates "boundary" uses with real cases: researchers designed, through prompt engineering, a system that translates a language without training on parallel text; others embedded generative AI in games for storytelling reactive to players; still others obtained novel insights into the astronomical phenomena of black holes. In cybersecurity, prompts simulate cyberattacks to design better defenses and uncover software vulnerabilities. All of these go beyond the models' "original scope," without retraining.

## Tradeoff / insight
Prompt writing is dependent on the target model (the GPT-3/GPT-4 vs Google Bard example is dated). The durable insight: prompt engineering is a cheap substitute for training, but it does not compensate for a weak base model — the effort should be calibrated to the criticality of the task, not applied systematically.
