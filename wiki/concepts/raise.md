# RAISE

**In one sentence** — a variant of ReAct enriched with a memory component to retain context across steps.

## In detail
RAISE is generally only mentioned in lists of emerging frameworks alongside ReWOO and Reflexion, with no associated definition or detail of how it works.

## Tradeoff / insight
RAISE is often cited without description or link in the survey literature. The usual decoding — RAISE = ReAct + a short/long-term memory module for multi-turn consistency — is not supported by the available primary sources. Treat it as a mere vocabulary reference.

## Primary source
No associated bibliographic reference in the survey literature — see the literature on conversational agents derived from ReAct with memory.
