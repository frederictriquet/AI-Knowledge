# Relay.app

**En une phrase** — Plateforme d'automatisation de workflows qui se distingue par le **human-in-the-loop** : insérer des étapes de validation/jugement humain au milieu d'automatisations, avec un assistant IA qui construit les flux en langage naturel.

## Type & intégration
SaaS propriétaire. Un assistant IA monte les automatisations à partir d'une description ; intégrations multiples ; **étapes manuelles intermédiaires** (revue, approbation, contexte humain) — le différenciateur vs Zapier. Intègre GPT, Claude, Gemini (tourne sur les derniers modèles Claude).

## Modèle économique
Propriétaire, freemium (constaté le 2026-06-17, facturation annuelle) :
- **Free** : 0 $ — 1 utilisateur, 200 étapes/mois, 500 crédits IA/mois.
- **Professional** : 19 $/mois — 750 étapes, 2 000 crédits IA.
- **Team** : 59 $/mois — 10 utilisateurs, 1 500 étapes, 2 000 crédits IA.
- **Enterprise** : sur devis.

## Coût LLM
**📦 Inclus (crédits IA) ou 🔑 BYOK** : crédits IA inclus dans chaque palier ; possibilité de brancher ses propres clés en alternative.

## À quoi ça sert
Automatiser des process **où l'humain doit garder la main** sur certaines décisions (approbations, vérifs) — un créneau que les outils 100 % automatiques couvrent mal. Voisin de Gumloop, Zapier AI, Make.

## Notes / à creuser
- Le HITL natif est l'argument clé ; pertinent pour des workflows à enjeu (finance, légal, ops).
- Modèle en étapes + crédits IA → estimer le volume mensuel.
